1. Estado y Reactividad state()

El núcleo de Spork UI es un Proxy ES2020 que intercepta escrituras y actualiza el DOM de forma quirúrgica. Usa una caché de funciones compiladas (__fnCache) que se invalida automáticamente al cambiar el estado — sin Virtual DOM, sin diffing.

Contador:

// Crear estado reactivo — devuelve un Proxy const app = state({ contador: 0, nombre: "Spork", activo: true }); // Cualquier escritura actualiza el DOM automáticamente app.contador++; // ✓ reactivo app.nombre = "vspk"; // ✓ reactivo app.contador = 0; // ✓ reactivo // Lectura directa sin efectos secundarios console.log(app.contador); // lectura normal // Múltiples objetos de estado independientes const ui = state({ visible: true, theme: "dark" }); const data = state({ items: [], loading: false });

2. Bindings de Texto y Formularios

Cinco atributos data-spork-* cubren todos los casos de binding reactivo:

data-spork-text data-spork-bind data-spork-if data-spork-class data-spork-style data-spork-attrs

Hola, 👋 (nombre largo)

Seleccionado:

// data-spork-text — muestra valor como texto <span data-spork-text="nombre"></span> <span data-spork-text="'Hola ' + nombre"></span> // expresión JS // data-spork-bind — two-way binding (input, checkbox, select) <input type="text" data-spork-bind="nombre"> <input type="number" data-spork-bind="numero"> // auto-convierte a Number <input type="checkbox" data-spork-bind="activo"> // Boolean <select data-spork-bind="opcion"></select> // data-spork-if — muestra/oculta (display:none) <div data-spork-if="activo">Visible si activo es true</div> <div data-spork-if="contador > 10">Expresión JS</div>

21. Temas Claro / Oscuro

Spork CSS usa variables CSS para temas. El tema claro es el predeterminado (:root), el oscuro se activa con .sz-dark o data-theme="dark". También respeta prefers-color-scheme automáticamente sin JS.

Tema actual:

Prueba el toggle — toda la página cambia de tema con transición suave.

☀️ Forzado claro

Usa .sz-light para forzar tema claro en un elemento concreto, aunque el resto de la página esté en oscuro.

🌙 Forzado oscuro

Usa .sz-dark para forzar tema oscuro en un elemento concreto.

// Toggle con JS document.body.classList.toggle(sz-dark); // Con estado reactivo Spork lt;body data-spork-class={sz-dark: temaOscuro}gt; // data-theme funciona igual que la clase document.documentElement.setAttribute(data-theme, dark); document.documentElement.setAttribute(data-theme, light); // Forzar claro/oscuro en un elemento concreto lt;div class="sz-light"gt;Siempre clarolt;/divgt; lt;div class="sz-dark"gt;Siempre oscurolt;/divgt; // Sin JS — respeta prefers-color-scheme automáticamente // :root sin .sz-light ni .sz-dark → sigue la preferencia del sistema
